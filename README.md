# stm32-baremetal-esc
Bare-metal STM32 firmware projects focused on embedded peripherals and ESC-related control concepts.

A bare-metal embedded firmware project built for the STM32F103C8T6.

The project focuses on building a register-level firmware foundation for timer control, PWM generation, ADC measurements, interrupts, and ESC-related control concepts.

## Target Hardware

- MCU: STM32F103C8T6
- Architecture: ARM Cortex-M3
- Programming Language: C
- Approach: Bare-metal / register-level programming

## Project Goals

- Build reusable bare-metal peripheral drivers
- Generate and control PWM signals using hardware timers
- Read analog signals using ADC
- Handle real-time events using interrupts
- Develop a structured embedded application
- Explore publicly shareable ESC-related control concepts

## Project Status

The project will be developed incrementally, with each module added as required by the application.
